# bin/ — Grok Build CLI advanced only

**Grok Bot users: ignore this folder.** Schedule your morning brief with `/install-overnight` in the Ops Bot — that creates a cloud **Routine** and does not use these files.

`overnight.sh` and `overnight.plist.example` exist for the optional **Grok Build CLI** path on macOS (local folder + launchd). They call the `grok` terminal command, which Grok Bot users do not install.

See `docs/GROK-BUILD-ADVANCED.md` before using either file.
